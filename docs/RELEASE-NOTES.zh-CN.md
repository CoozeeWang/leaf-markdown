# Leaf 1.0.4 — 发布准备稿

**简体中文** · [English](RELEASE-NOTES.md)

本版尚未发布。当前公开版本仍为 [1.0.3](https://github.com/CoozeeWang/leaf-markdown/releases/tag/v1.0.3)；此文件不表示已有 1.0.4 下载附件。

## 本轮变化

- 编辑或源码视图支持拖动大纲中的同父级、同层级标题，连同子章节移动整节正文，并可一次撤销。

- AI 编辑提示栏始终保持一个锁图标。PR #112。
- 提示块正文使用真正的占位提示；标题 Enter 进入正文，尾部空普通段落 Enter 退出提示块。已有“内容”等真实文字不删除。PR #115。
- 提示块正文富文本粘贴保留经过验证的命名深链接，复用普通正文的安全转换，并支持选区替换和单步撤销。

- 从外部软件粘贴富文本时，保留有效的 Ripple 正式版和开发版命名来源链接；编辑与源码视图转换一致，保存后仍保留链接目标。对应 PR #120、#121。
- 修复 Mac 外部文字拖放无反应的问题。富文本插入到落点，整次操作可一次撤销；文件拖放和内部文字移动保留既有行为。对应 PR #121。
- 普通编辑预览不再显示时间戳等字面量方括号的转义反斜杠；原始 Markdown、源码视图和代码内容不变。对应 PR #121。
- 减少长文及嵌套内容的重复解析，改善编辑焦点恢复和提示块文字选择反馈。对应 PR #119。
- 补充三语富文本、应用链接及 Windows 覆盖安装的数据保留说明。

Leaf 将 HTML 转为 Markdown，不承诺复制原软件的完整页面排版。应用链接仅支持已核对的 Ripple v2 正式／开发协议，不允许任意协议。粘贴、拖放和保存不会启动应用；在编辑视图按住 Mac ⌘／Windows Ctrl 单击，或在阅读视图单击，才请求打开目标。目标应用需要已安装并注册协议。

## 安装与升级

计划提供 `Leaf-1.0.4-windows-x64-setup.exe` 和 `Leaf-1.0.4-macOS-arm64.dmg`。这些是计划名称，正式下载链接、校验值与构建来源须在发布前填入。

先保存文稿并正常退出 Leaf，再手动覆盖安装。Mac 放入原 Applications 位置；Windows 使用原安装位置，如出现卸载选项，不勾选“删除应用数据”。保留应用标识、文档和设置位置。更新仍通过应用内检查版本／查看说明后，在浏览器下载官方包；不在应用内自动安装或退出重启。

系统要求与安全提示沿用[安装说明](INSTALL.zh-CN.md)。Mac 使用 ad-hoc 签名，未做 Developer ID 签名／公证；Windows 没有 Authenticode 签名。下载校验和 Minisign 分离签名不能代替操作系统发布者签名，不应关闭系统保护。
