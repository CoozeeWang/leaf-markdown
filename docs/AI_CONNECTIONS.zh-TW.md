# AI 輔助編輯與 MCP 連線

透過 MCP 連線，讓 AI 讀取、修改和審閱 Leaf 中的文稿。這份說明幫助你完成連線，並在日常寫作中使用 AI 輔助編輯。

Leaf 目前支援透過 MCP 連接 **ChatGPT、Claude（桌面版）和 WorkBuddy**，協助編輯與審閱文稿。使用前須完成對應軟體的 MCP 連線設定。

## 讓 AI 幫你連線

**直接在你熟悉的 AI 軟體中使用 Leaf。** 無需另行為 Leaf 設定模型 API，也不必使用 Codex、Claude Code 等程式設計工具。連線後，你可以沿用所選 AI 軟體及其帳號，在對話中提出修改要求。

MCP 是連線 Leaf 與 AI 軟體的方式。你無需瞭解它的技術細節，也可以把這份說明交給 AI，請它協助完成設定：

> 我想把 Leaf 連線到我使用的 AI 軟體。請根據這份說明，先確認我的作業系統和 AI 軟體，再逐步指導我完成設定。需要登入、授權或填寫金鑰時，請告訴我在哪裡操作。最後，請讀取我在 Leaf 中開啟的範例文稿，確認連線成功，暫時不要修改內容。

AI 可以提供操作指導；具備電腦操作能力的 AI 還可以協助完成部分設定。帳號登入、授權和金鑰輸入由你在對應介面完成，不要把金鑰發到對話中。

使用仍受所選 AI 軟體的帳號權限、訂閱與用量限制。ChatGPT 的連線還需要一個隧道金鑰，用來建立連線；它與為 Leaf 設定模型 API 是兩回事。

## 選擇連線方式

先開啟 Leaf 桌面版，進入「設定 → AI 輔助編輯」，開啟「啟用 MCP 連線」，再選擇要連線的 AI 軟體。使用期間保持 Leaf 和需要處理的文稿開啟。

| AI 軟體 | 連線方式 |
| --- | --- |
| ChatGPT | 透過 OpenAI 隧道連線，需要準備隧道 ID、連線程式和連線金鑰。 |
| Claude Desktop | 從 Leaf 新增擴充套件，在 Claude 中確認安裝。 |
| WorkBuddy | 從 Leaf 新增連線，再在 WorkBuddy 中啟用。 |

只需完成你所使用的軟體對應的步驟。不同用戶端的設定分別儲存，切換設定中的軟體選項不會清除其他連線。

### ChatGPT

Leaf 使用 OpenAI 的安全隧道，讓 ChatGPT 連線到電腦上正在執行的 Leaf。首次設定可以請 AI 對照 [OpenAI 隧道指南](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)協助完成。

1. **準備隧道。** 從 Leaf 設定中的連結開啟 OpenAI 隧道設定，建立或選擇一個 Leaf 專用隧道，將 Tunnel ID 填回 Leaf。確認該隧道關聯了你要使用的 ChatGPT 工作區，並具備建立、使用隧道所需的權限。
2. **選擇連線程式。** 按 Leaf 中的下載入口，下載適合系統與晶片的完整官方 `tunnel-client` 程式套件並解壓縮。在 Leaf 中選擇解壓縮後的程式；Windows 對應 `tunnel-client.exe`。請把整個解壓縮資料夾放在準備長期保留的位置。
3. **填寫連線金鑰。** 將 Runtime API key 輸入 Leaf 的連線金鑰欄，儲存設定。金鑰用於隧道連線，請勿放入聊天、截圖或問題回報。儲存後輸入框會清空；以後修改設定時留空，可以保留已有金鑰。
4. **在 ChatGPT 新增 Leaf。** 保持 Leaf 的 MCP 連線開啟，待本機服務就緒後，在 ChatGPT 網頁的外掛頁面新增自訂 MCP 伺服器，連線方式選擇 Tunnel，並選擇同一個隧道，將 Authentication 設為 **No authentication**（僅適用於此處的 Tunnel 連線；組織與工作區存取權限仍然適用）。按頁面提示完成建立和安裝。具體入口見 [ChatGPT 自訂 MCP 連線說明](https://developers.openai.com/api/docs/guides/custom-mcp-server)。
5. **確認可以讀取。** 在 ChatGPT 對話中透過 `@` 選擇已安裝的 Leaf 外掛，請它讀取一份已在 Leaf 中開啟的範例文稿。

如果帳號中沒有對應入口，或清單中找不到隧道，先核對帳號權限和工作區關聯。介面與可用範圍以 OpenAI 目前說明為準。

### Claude Desktop

1. 在 Leaf 中選擇 Claude Desktop，點選「新增到 Claude」。
2. 在開啟的 Claude 擴充套件安裝介面中，確認安裝 Leaf。
3. 保持 Leaf 開啟並開啟 MCP，在 Claude 對話中選擇 Leaf，請它讀取一份範例文稿。

正常安裝流程無需手動修改設定檔案，也無需另行安裝 Node 或 Python。

### WorkBuddy

1. 在 Leaf 中選擇 WorkBuddy，點選「新增到 WorkBuddy」，確認新增連線。
2. 在 WorkBuddy 的「专家·技能·连接器 → 连接器 → 自定义连接器」中啟用 Leaf。如果連線未出現，重新啟動 WorkBuddy 後檢視。
3. 保持 Leaf 開啟並開啟 MCP，在 WorkBuddy 對話中直接提出讀取範例文稿的要求，無需從「+」選單選擇 Leaf。

Leaf 會備份原有設定，並保留其他連線和設定。

### 怎樣確認連線成功

在 Leaf 中新增一份只寫有幾句話的範例文稿，再向 AI 提出：

> 請透過 Leaf 連線讀取我開啟的範例文稿，並概括它的內容。不要修改。

AI 能透過連線讀出目前文稿，才說明這一步已經完成。「設定已儲存」或「本機服務已就緒」表示連線準備取得進展，還需要這次實際讀取來確認。

## 開始寫作與審閱

連線後，你可以透過 AI 閱讀和梳理文稿、潤飾或修改內文、整理文件屬性、編輯註腳與表格，也可以讓它新增審閱批註，或根據已有批註修改文稿。直接在對話中說明需要完成的工作，以及是提出建議還是直接修改即可；同時開啟多份文稿時，請寫明檔名。修改結果會呈現在 Leaf 中，方便你對照檢查和繼續編輯。

### AI 可以存取哪些內容

開啟 MCP 並啟用對應用戶端後，AI 可以存取 Leaf 中**目前開啟的文稿，包括尚未儲存的內容**。相關文字會傳送到你使用的 AI 服務，請按文稿內容和自己的需要決定是否啟用。

Leaf 的 MCP 連線不會讓 AI 掃描資料夾、讀取最近檔案清單或自行開啟電腦上的其他檔案。關閉某份文稿後，該連線不能繼續存取它；關閉 MCP 則停止全部連線存取，但不會撤回已經傳送給 AI 服務的內容。

## 掌握修改過程

### 檢視與結束編輯

AI 開始編輯後，Leaf 會顯示編輯提示。此時該文稿暫時唯讀，你仍可瀏覽、捲動和尋找，也可以繼續編輯其他未被佔用的文稿。同一份文稿一次只允許一個 AI 編輯任務。

需要中止時，點選提示條中的「結束編輯」。**結束編輯會保留已經完成的修改，並恢復手動編輯；它不會自動撤回修改。**

### 檢查、還原與儲存

任務結束後，請在 Leaf 中檢查修改結果。如果不滿意，可以使用「還原」，一次撤回該 AI 任務的修改；也可以重新提出更具體的要求。

「修改已套用」表示文稿內容已經更新，「已儲存」才表示內容已寫入檔案。請留意儲存狀態；尚未選擇儲存位置的新文稿，仍需先儲存為檔案。自動儲存與草稿復原的區別，見[安裝與使用說明](INSTALL.zh-TW.md#開啟與儲存文稿)。

### 在對話旁閱讀文稿

支援即時閱讀面板的 AI 軟體，可以在對話旁顯示 Leaf 文稿。你可以請 AI「開啟這份文稿的即時閱讀檢視」，對照內文、屬性、註腳和批註檢視結果。

該檢視用於閱讀，手動編輯仍在 Leaf 中完成。能否顯示面板取決於 AI 軟體的支援情況；普通檔案附件或靜態預覽不會隨 Leaf 中的修改自動更新。

## 連線遇到問題

| 遇到的情況 | 可以先做什麼 |
| --- | --- |
| AI 找不到文稿 | 確認 Leaf 正在執行、MCP 已開啟、對應用戶端已啟用，且文稿已開啟；再讓 AI 重新讀取目前文稿清單。 |
| 設定已儲存，但 AI 仍無法讀取 | 檢查 AI 軟體中是否已安裝並啟用 Leaf。使用 ChatGPT 時，還需核對是否選擇同一個隧道，以及工作區關聯和權限是否正確。 |
| AI 編輯中斷或文稿暫時唯讀 | 檢視 Leaf 提示，必要時點選「結束編輯」。檢查已完成的修改，再讓 AI 重新讀取目前文稿並繼續。 |
| 修改後沒有儲存成功 | 檢視儲存提示。新文稿先選擇儲存位置；遇到檔案衝突時，保留目前內容，按提示處理或另存新檔。 |
| 更新後是否需要重新設定 | 在同一系統使用者下，保留原安裝位置、不解除安裝也不清空資料夾，正常覆蓋安裝會保留持久設定與應用程式資料。此說明不包含更換使用者、遷移資料或移動隧道程式資料夾的情況。暫時連線需要重新建立；外部 AI 軟體（包括 ChatGPT）的 MCP 授權可能需要重新確認。 |

### 關閉或清除連線

暫時不需要 AI 輔助時，可以關閉「啟用 MCP 連線」。已有連線設定會保留，正在進行的編輯任務會結束，已完成的修改也會保留。

如果不再使用某個用戶端，可以在其設定中清除連線設定。清除前請確認選取的軟體；其他用戶端設定與文稿不會因此刪除。AI 軟體中的 Leaf 外掛，以及 OpenAI 平台上的隧道和金鑰，需要在對應軟體或平台中另行管理。

仍無法解決時，歡迎透過 [GitHub Issues](https://github.com/CoozeeWang/leaf-markdown/issues) 回報。請附上作業系統、Leaf 與 AI 軟體版本、操作步驟和錯誤提示；截圖中請移除文稿私人內容與金鑰。
