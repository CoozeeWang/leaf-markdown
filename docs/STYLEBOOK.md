# Leaf Stylebook

**当前设计规则 · 2026-10-11 文档校准 · 源码基线 `0bd9aa17`（0.4.0-beta.2）**

本文件记录 Leaf 已确认的界面规则及现有行为。源码用于核对实现；发现实现与规则不一致时，应记录差异并确认处理方式，不能直接把现状当作新规则。任何获准的布局或入口变更都应同步更新本文。文档校准不代表 Windows、辅助技术或全部原生文件流程已经验收。

本次校准覆盖主界面、编辑与阅读样式、提示块、恢复窗口、PDF 导出及桌面窗口配置；实现入口见文末链接。本轮补充现有规则，并落实已确认的界面修正。涉及实际观感的改变仍需在安装版中检查。

## 1. 基本原则

| ID | 规则 | 判断方法 |
| --- | --- | --- |
| L01 | 内容优先 | 正文是主要阅读对象。品牌、文件身份、工具和状态帮助理解与操作，不争夺正文注意力。 |
| L02 | 层级清楚 | 优先用位置、字号、字重和留白区分层级；增加颜色、线条或卡片必须有明确用途。 |
| L03 | 操作可预测 | 同类控件的名称、位置、反馈和键盘行为一致。一个动作的名称必须准确描述对象与范围。 |
| L04 | 装饰不修改原文 | 文件名展示、标题编号、折叠、阅读边框与编辑标记属于界面。不要把它们写入 Markdown。 |
| L05 | 说明只写必要内容 | 说明紧靠相关控件，优先回答“影响什么”“下一步做什么”。不向用户解释内部实现。 |

桌面开发模式在现有品牌位置显示「Leaf Dev」，副标题为「开发模式 · 使用文档副本」，设置版本与文档窗口标题同步标识。该标识仅用于隔离的开发入口，不改变安装版布局或文档内容。

## 2. 视觉基础

以下均为 CSS 像素。系统缩放后的截图尺寸不能直接当作控件规格。

桌面使用独立的 Markdown 文档类型图标，沿用 Leaf 品牌视觉，并与应用图标保持可辨识的区别；两类图标随安装包离线提供。图标属于系统文件关联，不写入 Markdown 或附件；用户选择默认应用和系统的图标缓存／缩略图设置决定文件管理器的最终显示。

### 字体与层级

| 用途 | 基准 | 说明 |
| --- | --- | --- |
| 界面字体 | 系统无衬线，中文含 PingFang SC | 菜单、设置、状态与表单共用；独立于用户选择的正文字体。 |
| 品牌字样 | Palatino，20px／600 | 稳定的 Leaf 字样；副标题 11px。 |
| 普通界面文字 | 13px | 标签、菜单、按钮。 |
| 次级说明 | 12px | 相关控件旁的短说明，使用次级文字色。 |
| 元信息 | 11px | 时间、大小等简短信息。重要说明不能仅因空间不足就缩小。 |
| 分区标题 | 14px | 普通分组标题。 |
| 弹窗标题 | 18px／600 | 与正文、表单标签明确区分。 |
| 页面文件名 | 18px／500，次级文字色 | 文件身份，低于文章标题的视觉强度。 |
| 默认正文 | 17px，行高 1.85，最大宽度 780px | 用户可调整字体、字号、宽度。不能用 UI 字号替代正文设置。 |

### 尺寸与形状

| 用途 | 基准 | 例外 |
| --- | --- | --- |
| 普通控件／紧凑控件 | 36px／30px | 图标大小不等于点击范围；表格边缘工具等局部控件独立评估。 |
| 普通图标／紧凑图标 | 18px／16px | 24×24 画布、圆线端、圆转角、线宽 1.8；设置齿轮为 16px／1.6，减轻视觉重量。 |
| 提示块语义徽标 | 20px | Phosphor Fill 实心图标，保留原始 256×256 画布；不套统一圆圈，与操作控件的线性图标区分。 |
| 菜单项／控件圆角 | 6px／8px | 使用角色统一，不要求所有内容块同一圆角。 |
| 面板／弹窗圆角 | 12px／14px | 文档属性底块为 8px。 |
| 常规模态内边距 | 20px | 恢复窗口窄屏 16px；小型确认弹窗允许 24px。 |
| 常用间距尺度 | 4、8、12、16、24、32px | 新布局优先使用；已有光学修正和正文排版不机械替换。 |
| 工具分组间距 | 8px | 组内紧凑、组间可辨；分隔线只表达真实分组。 |

### 图片占位

图片显示不出来时，正文里用占位块代替那张图，Markdown 原文不变。

| 用途 | 基准 |
| --- | --- |
| 容器 | `--surface` 底、`--line` 细边、8px 圆角、内边距 12px 16px；宽度统一 `min(100%, 480px)`，不随文件名长短变化 |
| 图标 | 16px 线性 image 图标，`--muted` |
| 主行 | 13px／500，`--text`：结果 + 文件名 |
| 次行 | 12px，`--muted`：下一步怎么做，或文件仍在何处 |

文案只说结果与下一步，不解释加载过程；平台差异（例如 HEIC 在 Windows 上无法解码）由运行时平台名填入，不写死。占位块可点击时在文件管理器中显示该文件；悬停是轻底色变化，键盘焦点用单层强调细边。打印与导出 PDF 时去掉底色与边框，只留文字。

图标和辅助文字继承所在控件的语义颜色。不要用危险色表达普通阅读状态。`faint` 用于低优先级细节，不能替代重要提示。

正文 H1—H6 分别使用绿、橄榄绿、黄棕至棕色的既有层级。粗体、斜体、代码、链接和高亮各有内容色，值以 [样式源文件](../src/style.css) 为准；不要把这些内容色用于界面按钮分类。

重要文字需在实际背景上检查可读性，尤其是透明混色、深色主题和禁用状态。本书不将颜色变量表等同于完整对比度验收。

### 正文排版

编辑与阅读使用相同的正文内容色和标题字号层级。界面控件与正文排版分别维护，不能为统一控件规格而改变内容层级。

| 元素 | 当前规则 |
| --- | --- |
| H1—H6 | 相对正文字号依次为 1.76、1.38、1.16、1.05、1.05、1.05 倍；字重 600、行高 1.45，颜色区分层级 |
| 段落节奏 | 阅读视图主要内容块的上下间距为正文字号的 0.7 倍；编辑视图还需表达源码空行与光标位置，不按阅读视图的外边距机械对齐 |
| 行内格式 | 粗体字重 600；斜体、链接、代码和高亮保留各自内容色；标题内粗体继承标题颜色 |
| 列表 | 编辑与阅读的前五级无序标记依次为实心圆、空心圆、实心方、空心方、短横线；嵌套层级保持可辨，折叠不改写源码 |
| 普通引用 | 阅读视图使用 2px 左侧细线和轻底色；与带语义图标的提示块区分 |
| 代码 | 行内代码使用等宽字体与轻底色；阅读代码块保留换行，内边距 12px 16px，有语言标记时以 11px 元信息显示 |
| 表格 | 阅读表格字号为正文的 0.92 倍、行高 1.65；宽表在自身容器内横向滚动，不撑宽整篇正文 |
| 脚注 | 编辑模式的文末定义与侧栏保留正文的行内格式；光标进入定义时显示原始标记，源码模式保留 Markdown。阅读中的引用显示为上标，定义集中在文末并提供返回入口；PDF 同样采用文末列表，不承诺逐页页脚注释 |

正文的东亚与西文字体可分别选择并保存，两种视图共用同一组偏好。当前候选调用本机已安装的字体，不复制到安装包；新增自带字体须有明确允许应用分发的许可。菜单使用明确字体名称，每个实际字体家族只出现一次，只提供已确认可加载的选项。字体名称本身使用对应字体展示字形；点击或键盘确认后立即应用到正文，不提供固定示例框。方向键、Home／End、键入名称前缀导航，Enter／空格确认，Escape 取消；取消不改变偏好。界面语言只翻译控件，不隐藏任一文字类别。

已保存的字体失效时提示实际回退字体，保留原选择以便恢复。启动时重新检查可用性。旧的三类正文字体偏好继续保留内部标识，菜单显示实际匹配的字体名称，不改写用户尚未调整的偏好。

拉丁字母、数字、ASCII 标点、拉丁扩展字符及组合音标使用英文选择；汉字、中文标点和弯引号使用中文选择。所选字体缺少某个字形时继续使用系统回退；可用性表示本机字体能够加载，不承诺所有字形或字重齐全。已有真实粗体／斜体字形优先使用，缺失样式由浏览器按现有规则合成。正文、列表、表格、提示块和脚注使用同一字体搭配；应用控件、品牌与文档属性表保持界面字体。调整字体不改写 Markdown、不占用正文撤销记录；文档窗口同步已保存的选择。

编辑与阅读视图的 H1—H6 标题统一使用系统无衬线字体（`--ui-font`），不随正文字体选择改变。同一标题在两种视图中的字体应保持一致；标题与正文可以使用不同字体。源码视图与代码仍使用等宽字体，打印／PDF 按独立的打印规则处理。

编辑、阅读与导出需核对同一 Markdown 的内容结构。源码视图保留标记的可编辑性；标题装饰、编号与折叠不写回原文。普通 Markdown 遵循 CommonMark/GFM 的解析与渲染结果；提示块、高亮、脚注和文档属性等扩展另按各自功能验证，不能仅凭源码标记成对判断显示正确。

## 3. 状态与焦点

| ID | 状态 | 视觉与行为 |
| --- | --- | --- |
| L10 | 悬停 | 轻量底色变化。离开后恢复；不要产生第二个持续选中项。 |
| L11 | 命令当前候选 | 只允许一行高亮。鼠标移动和方向键共用候选；Enter 执行这一项。鼠标离开列表后可保留最后候选。 |
| L12 | 已生效值 | 用勾选、选中标签或明确文字持续表达；不能只靠悬停色。 |
| L13 | 输入焦点 | 命令搜索、正文查找／替换、设置下拉框、恢复列表／预览用单层强调细边线；不叠加外框。大纲改名沿用单层边线，文件名原地改名用细下划线。 |
| L14 | 滑杆焦点 | 滑杆整体不出现粗框；鼠标拖动后仍能用左右键微调，键盘定位在滑块上可辨。 |
| L15 | 内容内编辑 | 属性输入等使用淡底与细边／底线，避免改变尺寸导致光标或正文跳动。 |
| L16 | 禁用 | 控件弱化并实际不可执行。必要时说明原因；不能仅改外观。 |
| L17 | 阅读状态 | 模式控件淡绿底；正文视口四周 2px 灰绿色内框，使用强调色与画布各 50% 混合。 |

**适用边界：**“不要双框”不等于移除所有键盘焦点。普通按钮仍需清楚的焦点提示。设置标签保留选中底色；仅键盘聚焦时显示单层 1px 强调色细边线，向内绘制，不叠加外框。焦点移走后细边线消失，选中底色保留；鼠标点击不额外显示焦点边线。

## 4. 入口与工具分工

| 入口 | 负责什么 |
| --- | --- |
| 文件名旁的文档菜单 | 当前文档的历史版本／恢复入口；桌面版另提供定位文件和重命名，尚未保存的文档禁用后两项 |
| 桌面版系统“文件 > 最近打开” | 跨窗口共用的最近 Markdown 文档；通常仅显示文件名；同名时补最短可区分目录后缀，失效记录可清理。编辑窗口顶栏不重复提供入口；欢迎页保留最近文件入口。 |
| 顶栏保存与导出 | 保存当前文档；导出 PDF 或带附件的文档 |
| 顶栏设置 | 外观与排版、保存与恢复；底部显示版本与构建标记；语言切换使用欢迎页／顶栏独立入口，不在设置内重复 |
| 格式工具栏的“显示” | 文档属性、正文上方文件名、源码行号、编辑标记、标题多级编号 |
| 视图模式 | 编辑、阅读、源码 |
| 查找 | 当前文档内查找与替换 |
| 命令面板 | 按名称寻找功能，呈现已有快捷键 |
| 编辑工具栏 | 高频写作、插入与整理段落空行 |

查找替换主行的展开控件位于“选项”左侧；上下两行文本框等宽，输入框与相邻控件、控件之间统一使用 6px 间距；第二行“替换／全部替换”按钮按文字与内边距定宽，文字居中，靠左顺序排列。窄窗时两行控件分别换到各自输入框下方。复制富文本提供 HTML 与对应的可读纯文本回退；不支持 HTML 的目标程序不保证保留富文本格式，回退不包含 YAML 或 Markdown 标记。

“显示”是可连续切换多项的开关板。文档属性的显示开关在已有属性时只折叠或展开，不应删改 Markdown；无属性时开启会初始化空属性区用于编辑，放弃空属性编辑可移除空区。阅读模式的工具栏保留“复制富文本”和“显示”。

切换编辑、阅读、源码视图时保留当前实际可见的内容位置；编辑光标停在别处时，仍以屏幕所见为准。连续往返切换不应逐次漂移到文首。

英文名称统一为 “Clean Up Blank Lines”，工具栏与命令面板一致；“整理段落空行”的鼠标悬浮提示仅显示名称与现有快捷键。完整规则和例外见[空行整理说明](BLANK-LINES.md)，不塞入悬浮提示。整次整理可以一次撤销，再次整理不继续改变内容。

命令入口使用“列表＋放大镜”线性图标，不显示“命令”二字，也不使用 macOS 专属的 ⌘ 作为功能图标。图标仍须有“命令面板”的可访问名称及悬停提示。

高亮入口放在斜体之后、删除线之前，采用同系列线性荧光笔图标；悬浮提示显示名称和高亮快捷键。

**图片、附件、提示块直接放在编辑工具栏。**不要用含义不清的“更多”收纳设置、文件和编辑操作。

拖入图片或附件时保持正文可见，用 2px 强调色插入光标标出松手落点；标记跟随鼠标指针所在的视觉行，自动换行处不能从上一行末尾跳到下一行开头。拖放期间隐藏原文字光标，保留其位置，取消后恢复，不能同时出现两个光标。文档属性区不提供合法插入标记，松手后转到正文开头。整页“打开 Markdown 文件”提示只用于拖入文档或欢迎页，不遮住编辑中的附件拖放。

插入、拖入或粘贴图片后，在编辑视图立即显示图片预览，光标停在图片下方空一行的新段落，视图留在插入附近；后面的原有正文不作为这个新段落。源码模式保持源码模式，不自动切换视图。

桌面版的本地图片预览在悬停或键盘聚焦时，于左上角内缩 4px 提供 22px 浅色按钮，内含 14px 简洁文件夹轮廓；使用弱化颜色、不加阴影，点击直接定位源文件；悬停与可访问名称在 Mac 为“在 Finder 中显示”，其他系统为“在文件管理器中显示”。右键图片保留同名菜单项。普通左键点击仍用于编辑图片。远程图片不提供本地文件定位；缺图占位块保留可点击的定位入口，定位失败时在状态提示中说明原因。打印与 PDF 不显示这些操作控件。

图片悬停说明只保留“按住 ⌘／Ctrl 拖动图片”，显示在图片右上角，内缩 4px、高 22px，与左上角定位按钮顶部对齐；小图片让出定位按钮区域，超长省略，极小图片不叠加文字。拖动说明与定位按钮共用应用内的轻量悬浮提示：12px 正常字重、随主题变化的浅色背景／弱化文字、细边框和轻阴影；同一时刻只显示当前悬停目标的说明。不再用系统原生 title 承载图片操作说明，也不在图片边缘额外显示文字条。编辑预览中的图片按住 macOS Cmd 或 Windows／Linux Ctrl，再用左键拖动可移动；普通点击或不带修饰键的拖动不移动图片。移动复用 2px 插入光标，保留原图片引用，整次操作可一次撤销。独立图片按段落放入，行内图片保留行内形式；图片本身作为链接的全部内容时连同外层链接移动。Esc、松开修饰键、拖出编辑区、原位松手，以及属性区或会破坏图片语法的位置均取消移动。拖动到编辑区上下边缘可滚动到其他段落。

列表之间插入图片默认形成独立段落。图片独占一行时，Tab 增加源码缩进，Shift+Tab 减少缩进；取消到零缩进仍被 Markdown 解析为列表续行时，补一个分隔空行，让图片脱离列表。图片链接、预览、阅读与导出依据同一源码结构；仅打开文档不改写原文。

行内格式按钮与快捷键在 macOS、Windows 使用同一规则：斜体、粗体与删除线遇到标点边界无法解析时，只在需要的一侧、标记外补一个普通空格；已有空白不重复补入。选区首尾空白保留在格式标记外，多行或跨段落选择按正文行分别添加格式，保留空行、列表／引用前缀和标题标记。行内代码根据内容中的反引号选择更长的分隔符。属性、代码块和部分选中的代码／链接目标等语法内容不由正文格式操作改写。整次格式操作可一次撤销／重做；取消格式保留已有空格。仅打开、阅读或导出文档不自动修订原文中的格式写法。

编辑模式在普通正文按 Enter 时，新行从第 1 列开始，不继承上一行无结构意义的 1–3 个前导空格；不批量清理原文已有空格。列表、引用、代码、脚注定义和源码模式仍遵循对应的换行与缩进规则。

### 欢迎页、专注模式与侧栏

欢迎页沿用品牌字体，Leaf 字样为 26px，描述为 14px；新建、打开、最近文件和语言入口使用 44px 高控件，图标按钮为 44px 方形。右上角设置使用 36px 控件。这里的入口规格是欢迎页的独立层级，不套用编辑工具栏的紧凑尺寸。

窗口右下角的专注按钮及命令面板可切换专注模式。进入后隐藏顶部工具区、格式工具栏和底部状态栏，同时让这些区域退出键盘与辅助技术导航；焦点移到当前编辑区或阅读区，为正文留出空间。Escape 退出后恢复工具区的可操作性，焦点仍在正文。专注模式不自动关闭已展开的大纲或脚注侧栏。

底栏在字数统计与专注按钮之间提供正文缩放的「− / 百分比 / +」。加减按 50%、75%、90%、100%、110%、125%、150%、200% 逐档切换，到达边界后对应按钮禁用。点击百分比打开向上展开的档位菜单，以勾选标明当前比例，并提供「恢复 100%」；支持方向键选择、Enter 应用和 Escape 返回触发控件。底栏按钮高度为 30px，保持轻量，不增加独立滑块。百分比按钮获得焦点时不显示高亮底色、外框或阴影，菜单仍保留当前档位勾选和键盘焦点提示。

正文缩放覆盖编辑、源码与阅读中的正文、文档属性、文档内图片、表格、代码和文末脚注；应用工具栏、查找工具、底栏、大纲和脚注侧栏保持原尺寸。100% 使用现有正文排版设置，缩放不改字号偏好、Markdown、附件、文档修改状态、撤销记录或打印／PDF。尽量保持当前阅读位置和可见光标位置；正文鼠标命中随显示比例校准。每个窗口初始为 100%，同窗口切换文档和视图保留比例，重新启动不保存。专注模式下仍可用快捷键缩放。

大纲位于左侧，脚注位于右侧，展开时正文重新排版。两者可调整宽度；窗口宽度不超过 1000px 时只同时展开一个，打开另一侧会收起原侧。窗口从宽变窄且两侧均已打开时，保留脚注侧栏。

编辑模式将全部脚注定义集中显示在正文之后的脚注区，以界面分割线和「脚注」标识区分；字号为当前正文字号的 85%，光标所在行、标题和代码等内容也保持小于正文。编号复用脚注侧栏的圆角方框底色。脚注默认只读预览；双击或键盘聚焦后按 Enter 进入编辑，显示可见光标和轻微编辑底色；Esc 或点击正文退出并恢复预览；键盘聚焦时以明显的主题色外框标识当前脚注，聚焦本身不进入编辑。组合输入提交前不重建或强制锁定正在编辑的控件。分割线不写入 Markdown。脚注内 Enter 和多段粘贴继续当前脚注；新增脚注仍通过正文引用／插入功能创建。正文末尾按 Enter 可自然续写，正文增长时脚注区随之后移；不另设返回正文按钮。脚注标题旁保留「双击或按 Enter 编辑脚注」提示，与标题按文字基线对齐。正文中的普通删除不能跨边界吞掉脚注；明确的全文选中删除仍有效。

打开文档仅重排脚注的显示，不修改文件。实际编辑后才将定义完整移到原文末尾，与该次编辑共同撤销；输入法组合期间延后整理。源码模式保持 Markdown 原文，阅读和 PDF 沿用集中脚注列表。文末脚注区与侧栏、浮框即时同步，连续输入复用控件，不因每次输入重新创建正在组合输入的编辑器。

脚注侧栏跟随正文的编辑、阅读和源码模式，不提供独立模式开关。编辑模式复用正文的 Markdown 渲染与光标处标记显隐规则，源码模式显示原始标记，阅读模式只渲染并隐藏删除入口。侧栏修改即时写回文档，撤销／重做使用文档历史；模式切换保留脚注原文与编号，不能在中文输入法组合输入期间重建正在编辑的控件。

新增脚注浮框的撤销／重做也使用文档历史：Mac 为 ⌘Z／⇧⌘Z，Windows 为 Ctrl+Z／Ctrl+Y（亦支持 Ctrl+Shift+Z），原生菜单与工具栏行为一致。撤销脚注内容时同步浮框；撤销插入本身时一并移除引用和定义、关闭浮框并将焦点返回正文，随后可直接重做。组合输入期间不拦截候选输入的撤销快捷键。

编辑模式在正文行内手打完成脚注引用时，自动补齐空的文末定义，使用与工具栏相同的编号与编辑入口；先成对输入括号、再填引用标识同样有效。光标仍在已有括号内时保留正在输入的完整标识，离开引用后再补齐和编号。中文输入法组合输入期间不改写引用，提交后才允许补定义，输入与补齐共用一次撤销。空定义不要求先填写内容，光标离开引用后即可显示上标。已存在的缺少定义引用，在侧栏获得编辑焦点时补齐；打开文档本身不修改原文。源码模式、粘贴、代码示例及行首可能尚未写完的定义不自动补齐。

### 批注与隐藏注释

右侧栏共用宽度和收起入口，标签由左到右为「批注」「脚注」，各自显示条数，以底线表示当前标签。展开后正文重新排版，保留既有窄窗和宽度调整规则。点击正文批注自动切到批注页，点击脚注入口切到脚注页；切换不改文档。只有脚注、没有批注的文档首次展开优先显示脚注。

范围批注沿用 CriticMarkup `{==正文==}{>>批注<<}`，正文显示主题淡底色，范围末尾和位置批注 `{>>批注<<}` 都显示小号上标气泡：图标 11px、操作区域 17px，点击定位侧栏。气泡提供键盘焦点、可访问名称及悬停提示，显示装饰不写入 Markdown。批注文字只显示在侧栏；Obsidian `%%注释%%` 在正文隐藏、不留下气泡，在侧栏列为「隐藏注释」。源码模式显示完整标记。单独 `{==文字==}` 作为高亮，不计入批注。

批注卡片提供对应正文摘录、批注内容和类型，单击摘录定位正文，双击内容或「编辑」进入编辑。输入即时写回文档；Escape 或失焦结束编辑，使用文档共享撤销／重做，不重建中文组合输入中的控件。阅读模式只读，隐藏编辑和删除。删除范围批注移除范围包装和批注，保留正文及已有 Markdown 格式。

添加批注位于脚注入口之后，并提供右键、命令面板与原生编辑菜单入口。Mac 为 ⌥⌘A，Windows 为 Ctrl+Alt+M；悬停提示遵循名称＋圆括号快捷键，菜单使用快捷键列。选中文字添加范围批注，无选区添加位置批注；首版只生成同一普通正文段落内的完整选区，跨段落／结构、部分格式和交叠选区拒绝添加，保留原文及选区，并在现有消息区域解释调整方法。

批注采用既有语法直接随 `.md` 保存，不加入 Leaf 专属 ID 或作者日期。打开文件和模式切换不改原文。代码、转义、YAML 属性不识别为批注；未闭合和不能可靠解析的标记保持可见。新增／删除／替换等其他 CriticMarkup 修订形式暂不执行或解释为定稿，编辑、阅读及 PDF 保持标记可见原样。

PDF 和复制富文本去掉批注内容、隐藏注释及范围批注底色／气泡，保留被批注正文。导出 PDF 时有批注的文件在工具栏下方现有导出说明区域持续显示「PDF 不包含批注、隐藏注释及批注标识。」；有修订标记时另显示「本文包含未处理的修订标记，将按原样导出。」。提示使用 12px 次级文字色，居中与原说明对齐，不是错误框，不进入纸面。三语使用正式语言资源，英文允许换行；提示与工具栏跟随主题，纸面保持浅色。

- 未搜索时按设置、文件、编辑、插入与格式、视图、恢复分组；搜索后显示匹配项。
- “设置”分组内直接写“外观与排版”“保存与恢复”；“显示选项”打开格式工具栏的显示控件。搜索“设置”仍能找到相关设置。
- 名称左对齐，快捷键右对齐；同一行只对应一个命令。
### 命令面板

- “插入提示块”及类型菜单按当前界面语言显示名称，Callout 保留为搜索别名；类型使用对应实心徽标，源码类型值保持不变。编辑区、阅读区、导出和菜单共用 Phosphor Fill SVG（MIT，许可证随资源保留）。图标 20px，与标题垂直居中；图样留白透出背景，不加额外圆圈，不使用 emoji。
- 提示块使用较重的语义图标，普通操作控件继续使用线性图标。按含义保留不同轮廓：信息 info、完成 check-circle、失败 x-circle、注意 warning、警告 warning-octagon、提示 lightbulb、笔记 note、摘要 text-align-left、待办 list-checks、问题 question、问题排查 bug、示例 flask、引用 quotes。色彩沿用提示块自身主题色。
- 命令搜索输入为专用规格：15px 字号、42px 高、9px 圆角。
- 无结果明确显示空状态；列表内部滚动，末项可通过鼠标和键盘到达。
- Tab 保持输入位置，方向键选命令，Enter 执行，Escape 关闭；中文组合输入期间不执行候选命令。

## 5. 设置与显示

设置保留两页，顺序为 **外观与排版 → 保存与恢复**。显示类开关位于格式工具栏的“显示”控件中。设置底部显示版本号和构建标记。设置与“显示”面板内，Tab／Shift+Tab 按顺序经过可用控件，跳过禁用项；焦点越过面板边界时关闭面板并留在新目标，不强制跳回入口。Escape 主动关闭时返回各自入口。

- 设置标签与内容之间保留一条中性细分隔线；内容使用整齐的行，不堆叠多层卡片和横线。
- 设置行的标签在左、控件在右。说明优先紧随对应标签，空间不足时同行内容自然换行。
- “仅影响显示，不修改原文”放在“显示”控件中“标题多级编号”右边。
- “¶ 段落结束　↵ 换行”放在“显示”控件中“编辑标记”右边；标签本身不再追加 ¶。
- 上述说明使用 12px 次级绿色文字。无需另设大段说明。
- 正文字号 14—24px，步进 1px；正文最大宽度 600—1100px，步进 20px。鼠标与方向键均可调整，数值右对齐。
- “历史版本与草稿保留时间”明确对象，期限下拉框放在右侧；“查看可恢复草稿”位于下一行右侧，与期限下拉框右边缘对齐，按文字所需宽度排列，底部留出与版本信息的间距。两个控件不强制同宽。
- 文字按钮换行时按文字起始侧对齐，避免多行居中；单行标签可保留整体居中，图标控件保持图标居中。设置标签的选中底色明确，未选中项的悬停底色较淡，避免同时出现两个同等强度的高亮。
- 设置始终位于查找等正文工具之上，不得出现看得见却点不到的标签。

## 6. 文件身份与文档属性

### L20 文件身份

macOS 窗口标题栏、工具栏文件名与页面文件名指向同一文件；文章 H1 属于正文，不替代文件名。

页面文件名前有轻量文件图标，下方使用与内容区同宽的细线。阅读模式的文件名不加正文标题折叠箭头。装饰不进入复制的原文或 Markdown。

双击 macOS 标题栏中央或页面文件名，在原地修改。Enter 提交，Escape 取消；离开输入位置取消并恢复正常显示。输入无大弹窗、无双框。保留目录与扩展名，拒绝覆盖同名文件，提交后同步各处名称。

### L21 文档属性

属性区使用轻底色和 8px 圆角，不用多层框线。底色为 `accent-soft` 35% 与 `canvas` 混合。

标题折叠箭头、字段类型图标、添加加号共用 28px 图标列；“文档属性”、字段名、“添加属性”的文字起点对齐。字段名为 12px 次级色／常规字重，值为正常主文字，避免靠粗框区分。

字段和值都可编辑。现有文本、数字、日期值在 Enter 或失焦时提交，Escape 取消暂存修改；数字／日期空值或无效输入失焦恢复已保存值，不能显示空白却仍保留旧值。列表新增项与枚举候选编辑的 Escape 取消暂存，不更改原持久值。字段名错误紧邻所在行，恢复有效名称或取消后清除旧提示。字段名拒绝空值和重复值；修改名称不应破坏值与注释。添加行分别提供“属性名”“属性值”。属性源码只显示对应 YAML；切换与删除分隔符不应卡死或吞入正文。

编辑视图中，从正文全选、复制、剪切或替换时只处理正文，不包含文档属性；属性区折叠时规则相同。源码视图仍可全选包含属性的完整 Markdown。

### 三语与语言选择

语言选择位于编辑器右上角设置控件右侧，以及欢迎页最近打开控件右侧；设置面板不重复提供语言入口。两个入口使用与 Ripple 一致的地球图标，点击图标按钮打开 Leaf 语言菜单，当前选择有明确标记，并支持方向键、Enter 和 Escape；键盘焦点明确可见；两个入口共享选择与保存状态，提供跟随系统、简体中文、繁體中文（台灣）、English；语言名称始终使用各自文字。首次启动和升级默认跟随系统，不支持的语言使用英文；手动选择在保存成功后应用并同步所有文档和导出窗口。

切换语言即时更新界面、工具提示和辅助技术名称，保留正文、文件名、属性值、自定义标题、选区及撤销记录。组合输入期间推迟受影响界面的更新。新文件名称和新插入的模板使用当前语言；无自定义标题的提示块仅翻译显示标题，不写回 Markdown。

简中使用“脚注、撤销”，台湾繁中使用“註腳、還原”，英文使用“Footnote、Undo”。恢复文件内容与 Undo 是不同操作。动态消息翻译完整句，英文数量区分单复数；按钮容纳较长英文，导出工具栏可换行，保持键盘和鼠标可达。

| 成功／一般反馈 | 已重命名、无需整理 | 显示 4 秒后消失；新消息取消旧计时，旧计时不能清除新错误。常规已保存／已自动保存在底部稳定显示。 |
| 进行中 | 正在保存、等待自动保存 | 随任务结果更新；不能按固定时间伪装为成功。 |
| 待处理 | 选择保存位置、恢复后需要检查并保存 | 保留到相关条件解决，或由用户点击关闭提示。关闭不改变文件状态。 |
| 错误 | 保存失败、文件被其他程序修改 | 可见且持续保留，说明下一步；提供关闭按钮，不能因时间到而消失。关闭不代表已保存或已解决。 |
| 恢复入口 | 发现恢复记录 · 查看 | 可直接点击打开当前文档的历史版本与草稿；记录变化后刷新，无相关草稿时隐藏；可关闭，本次打开期间不因窗口重新获得焦点而反复出现。 |

常规“等待自动保存／正在保存／已保存”放在底部状态栏光标位置旁，保持单行和稳定高度，只更新文字，不因出现或消失挪动正文。保存错误、待处理、恢复入口及其他操作反馈仍放在编辑工具栏下方、正文上方的提示区域，不放在文档名控件内。同一时刻只显示一条提示，文字与关闭按钮在提示框内上下居中；长文字换行并可滚动，关闭按钮始终可见。原文件不可用时，提示内可直接提供“重新定位原文件”和“另存为”操作；关闭提示不改变编辑、保存位置或恢复记录。其他成功／一般反馈为 4 秒，进行中随任务更新，错误／待处理与恢复入口可手动关闭。短暂提示消失后显示尚未关闭的恢复入口；未关闭的错误不能被重命名、格式整理或等待自动保存遮掉，成功保存或重新定位原文件可更新相关错误。恢复提示关闭只隐藏入口，不删除记录，仍可从设置打开历史版本与草稿。

欢迎页的“最近打开”失败也在主界面固定提示区域显示，不放进可滚动的最近文件列表；提示保持可见，用户可关闭，清理失效记录后自动移除对应错误。

通过系统文件管理器打开文档时，如果尚未成功创建编辑窗口，打开失败以标题为“Leaf”的原生对话框说明原因；应用继续运行，已有窗口的未保存内容保持原状。

后台反复读取同一文件失败时，同一错误只提示一次；用户关闭后，在失败状态未变化时不重新弹出。文件重新可读时清除旧错误，路径或错误原因变化后才重新提醒。原文件找不到时要说明当前编辑内容仍保留，并引导重新定位原文件或另存为。

用户主动操作的成功／一般反馈通过独立的温和通知区域告知辅助技术。后台自动保存、自动保存开启和外部自动载入不重复播报；错误和待处理提示也由该通知区域告知辅助技术。重复操作可再次通知，新状态取消尚未发出的旧通知。实际屏幕阅读器体验需单独验证。

### L31 恢复与删除

恢复面板先选记录、看预览，再恢复或作为新文档打开。原文件、当前编辑内容和恢复记录是不同对象，文案必须说明影响范围。

- 草稿动作名：**删除该草稿**；历史版本动作名：**删除该版本**。删除入口位于每条记录的文件名右侧，使用 16px 线性垃圾箱图标、28px 点击区域；常态弱化，悬停显示危险色，提供悬停提示和无障碍名称。窗口左下不再放独立删除按钮。点击后独立确认，不能直接删除。
- 点击后打开独立确认弹窗，显示文档名和“只删除选中的记录，无法撤销。原文件和其他记录不受影响。”
- 默认焦点在“取消”；Escape 取消。原面板暂不可操作，Tab 留在确认弹窗中。
- 不在同一按钮原地改字后接受第二次点击作为删除确认。
- 窗口底部只写“仅保存在本机，最多保留 20 个历史版本。”删除影响在确认弹窗说明，避免草稿与历史版本对象混用。
- 删除只针对被点击垃圾箱所属行的记录 ID，不以当前预览项代替；其他草稿、版本和原文件保留；记录已变化时拒绝删除旧目标。
- 成功后刷新列表、欢迎页入口及当前文档提示；失败显示原因，保留可重试和取消的路径。

删除真实记录的人工验收使用专用测试数据，不能拿用户文档的恢复记录做破坏性试验。

## 8. 快捷键、平台和输入

| 动作 | macOS | Windows |
| --- | --- | --- |
| 新建／打开／保存 | ⌘N / ⌘O / ⌘S | Ctrl+N / Ctrl+O / Ctrl+S |
| 导出 PDF | ⌘E | Ctrl+E |
| 循环视图：编辑 → 阅读 → 源码 | ⌘R | Ctrl+R |
| 命令面板／文内查找 | ⌘P / ⌘F | Ctrl+P / Ctrl+F |
| 设置 | ⌥⌘, | Ctrl+Alt+, |
| 高亮 | ⌘= | Ctrl+= |
| 行内代码 | ⌥⌘C | Ctrl+Alt+C |
| 放大正文一档 | ⇧⌘= | Ctrl+Shift+= |
| 缩小正文一档 | ⇧⌘− | Ctrl+Shift+− |
| 正文恢复 100% | ⇧⌘0 | Ctrl+Shift+0 |

正文缩放严格要求 Shift，不占用原高亮快捷键。等号、减号和数字 0 按键在 Shift 下产生的字符均按原按键识别。设置、命令面板与组合输入期间不拦截缩放快捷键；不使用系统辅助功能的 Option+Command 缩放组合。

悬浮说明中的快捷键统一用圆括号包裹，例如 `Save (⌘S)`；标题范围写作 `(⌥1–6)`。菜单与命令列表仍使用独立的快捷键列。

显示与实际绑定都按系统选择；不能只换提示文字。macOS 的字母、数字、反斜杠、逗号、句号、等号及减号组合共用修饰键绘制与可访问名称。旧版 ⌘⇧E 导出绑定不再作为规范。平台转换仅用于界面快捷键，不能替换文档中的符号。

中文输入法没有候选窗口也可能影响快捷键处理；必须以实际输入状态验证。原生菜单、编辑区和属性输入中的同一快捷键应有一致结果，不触发第二个窗口或后台欢迎页。

## 9. 窗口、弹层与可达性

- 主窗口和文档窗口的初始尺寸为 1100×800，最小为 900×480；PDF 导出窗口初始为 950×800，最小为 720×480。按各自窗口角色检查常规与最小尺寸、明暗主题和三语布局。浏览器测试可继续覆盖更窄的响应式布局，但不能称之为桌面最小窗口。
- 窄窗允许工具栏分行，不能把图片、附件、提示块等必要入口裁掉。
- 菜单在窗口边缘保留至少 8px，超高时内部滚动。上下文菜单不因正文滚动容器而不可达。
- 侧栏展开后正文重新排版，不覆盖正文；长文件名、省略路径可获取完整信息。
- 弹窗标题和动作可到达；大列表与预览内部滚动。嵌套确认只操作最上层，取消后返回触发位置。
- 保留控件名称、选中、展开与禁用语义。颜色之外还要有文字、勾选或形状提示。
- 页面缩放、长中文标签、键盘操作都应纳入复核；不要仅依据截图宣布交互通过。

## 11. 打印与 PDF 导出

PDF 导出工具栏的保存按钮使用 14px 界面字体。

导出预览使用打开导出窗口时的文档快照；预览中的选项不修改正在编辑的 Markdown。文档属性和标题编号可独立选择，正文内容保留原样。

纸面使用白底和独立的打印尺寸：正文 11pt、行高 1.8；H1—H6 依次为 22、17、14、12、11.5、11pt。浏览器打印样式以 A4、18mm 页边距为基准；原生打印还经过平台打印设置，实际纸张、方向和分页需以系统打印窗口及生成的 PDF 核对。预览连续显示内容，不显示实际分页。

打印时隐藏导出工具栏、帮助和错误提示，以及文档内的操作控件；缺失、损坏或平台不支持图片的占位仅保留文字，加载结束后允许打印占位，不因为已有明确占位而阻止打印。标题尽量不单独落在页尾，表格表头可跨页重复，行和提示块尽量不在内部断开；这些是排版约束，不能代替对实际跨页结果的检查。

PDF 纸面采用阅读浅色主题的语义配色，标题、粗斜体、代码、高亮、链接、引用和表格的颜色保持一致；纸张始终为白色，纸面字号、页边距和分页规则保持独立。导出工具栏与窗口背景跟随应用的明暗主题（包括跟随系统），主题变化不改变纸面颜色，工具栏不进入打印结果。

## 系统文件管理器新建

系统入口使用三语定稿的「使用 Leaf 新建 Markdown 文档」／「使用 Leaf 新增 Markdown 文件」／「Create a Markdown Document with Leaf」。Mac Finder「服务」按系统语言显示，未支持语言回退英文；Leaf 内语言选择不即时改写系统服务名称。新文件名按 Leaf 当前有效语言生成，简中／繁中为 `未命名.md`，英文为 `Untitled.md`；重名加空格与递增数字，打开后沿用标题改名。Mac 服务接受单选文件夹或文件；Windows 使用文件夹和背景右键菜单。此操作没有编辑器窗口可承载状态时，失败使用已翻译的「Leaf · 新建文档」标题的原生提示，不覆盖已有文件。

Windows 安装器优先使用 Tauri 官方 English／SimpChinese／TradChinese 资源，显示语言选择器；首次按系统匹配，未支持语言回退英文，后续可记住安装语言。文件夹／背景右键文字按安装时的语言写入，重新安装可更新，应用内切换不即时改写右键菜单；安装器不覆盖已有 Leaf 应用语言偏好。
