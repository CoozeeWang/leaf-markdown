# Leaf Stylebook

**当前设计规则 · 按 0.4.0-beta.2 源码校准**

本文件记录 Leaf 当前的界面规则。规则以现行源码和后续用户确认的改动为准；任何新增布局或入口都应同步更新本文。它不代表 Windows、辅助技术或全部原生文件流程已经验收。

本次校准依据包括 `src/main.js`、`src/style.css`、`src/reading.css` 和 `src-tauri/tauri.conf.json`。涉及实际观感的改变仍需在安装版中检查。

## 1. 基本原则

| ID | 规则 | 判断方法 |
| --- | --- | --- |
| L01 | 内容优先 | 正文是主要阅读对象。品牌、文件身份、工具和状态帮助理解与操作，不争夺正文注意力。 |
| L02 | 层级清楚 | 优先用位置、字号、字重和留白区分层级；增加颜色、线条或卡片必须有明确用途。 |
| L03 | 操作可预测 | 同类控件的名称、位置、反馈和键盘行为一致。一个动作的名称必须准确描述对象与范围。 |
| L04 | 装饰不修改原文 | 文件名展示、标题编号、折叠、阅读边框与编辑标记属于界面。不要把它们写入 Markdown。 |
| L05 | 说明只写必要内容 | 说明紧靠相关控件，优先回答“影响什么”“下一步做什么”。不向用户解释内部实现。 |

## 2. 视觉基础

以下均为 CSS 像素。系统缩放后的截图尺寸不能直接当作控件规格。

### 字体与层级

| 用途 | 基准 | 说明 |
| --- | --- | --- |
| 界面字体 | 系统无衬线，中文含 PingFang SC | 菜单、设置、状态与表单共用；独立于用户选择的正文字体。 |
| 品牌字样 | Palatino，20px／600 | 稳定的 Leaf 字样；副标题 11px。 |
| 普通界面文字 | 13px | 标签、菜单、按钮。 |
| 次级说明 | 12px | 相关控件旁的短说明，使用次级文字色。 |
| 元信息 | 11px | 时间、大小等简短信息。重要说明不能仅因空间不足就缩小。 |
| 分区标题 | 14px | 普通分组标题。 |
| 弹窗标题 | 18px／600 | 与正文、表单标签明确区分。 |
| 页面文件名 | 18px／500，次级文字色 | 文件身份，低于文章标题的视觉强度。 |
| 默认正文 | 17px，行高 1.85，最大宽度 780px | 用户可调整字体、字号、宽度。不能用 UI 字号替代正文设置。 |

### 尺寸与形状

| 用途 | 基准 | 例外 |
| --- | --- | --- |
| 普通控件／紧凑控件 | 36px／30px | 图标大小不等于点击范围；表格边缘工具等局部控件独立评估。 |
| 普通图标／紧凑图标 | 18px／16px | 24×24 画布、圆线端、圆转角、线宽 1.8；设置齿轮为 16px／1.6，减轻视觉重量。 |
| 提示块语义徽标 | 20px | Phosphor Fill 实心图标，保留原始 256×256 画布；不套统一圆圈，与操作控件的线性图标区分。 |
| 菜单项／控件圆角 | 6px／8px | 使用角色统一，不要求所有内容块同一圆角。 |
| 面板／弹窗圆角 | 12px／14px | 文档属性底块为 8px。 |
| 常规模态内边距 | 20px | 恢复窗口窄屏 16px；小型确认弹窗允许 24px。 |
| 常用间距尺度 | 4、8、12、16、24、32px | 新布局优先使用；已有光学修正和正文排版不机械替换。 |
| 工具分组间距 | 8px | 组内紧凑、组间可辨；分隔线只表达真实分组。 |

### 图片占位

图片显示不出来时，正文里用占位块代替那张图，Markdown 原文不变。

| 用途 | 基准 |
| --- | --- |
| 容器 | `--surface` 底、`--line` 细边、8px 圆角、内边距 12px 16px；宽度统一 `min(100%, 480px)`，不随文件名长短变化 |
| 图标 | 16px 线性 image 图标，`--muted` |
| 主行 | 13px／500，`--text`：结果 + 文件名 |
| 次行 | 12px，`--muted`：下一步怎么做，或文件仍在何处 |

文案只说结果与下一步，不解释加载过程；平台差异（例如 HEIC 在 Windows 上无法解码）由运行时平台名填入，不写死。占位块可点击时在文件管理器中显示该文件；悬停是轻底色变化，键盘焦点用单层强调细边。打印与导出 PDF 时去掉底色与边框，只留文字。

图标和辅助文字继承所在控件的语义颜色。不要用危险色表达普通阅读状态。`faint` 用于低优先级细节，不能替代重要提示。

正文 H1—H6 分别使用绿、橄榄绿、黄棕至棕色的既有层级。粗体、斜体、代码、链接和高亮各有内容色，值以 [样式源文件](../src/style.css) 为准；不要把这些内容色用于界面按钮分类。

重要文字需在实际背景上检查可读性，尤其是透明混色、深色主题和禁用状态。本书不将颜色变量表等同于完整对比度验收。

## 3. 状态与焦点

| ID | 状态 | 视觉与行为 |
| --- | --- | --- |
| L10 | 悬停 | 轻量底色变化。离开后恢复；不要产生第二个持续选中项。 |
| L11 | 命令当前候选 | 只允许一行高亮。鼠标移动和方向键共用候选；Enter 执行这一项。鼠标离开列表后可保留最后候选。 |
| L12 | 已生效值 | 用勾选、选中标签或明确文字持续表达；不能只靠悬停色。 |
| L13 | 输入焦点 | 命令搜索、正文查找／替换、设置下拉框、恢复列表／预览用单层强调细边线；不叠加外框。大纲改名沿用单层边线，文件名原地改名用细下划线。 |
| L14 | 滑杆焦点 | 滑杆整体不出现粗框；鼠标拖动后仍能用左右键微调，键盘定位在滑块上可辨。 |
| L15 | 内容内编辑 | 属性输入等使用淡底与细边／底线，避免改变尺寸导致光标或正文跳动。 |
| L16 | 禁用 | 控件弱化并实际不可执行。必要时说明原因；不能仅改外观。 |
| L17 | 阅读状态 | 模式控件淡绿底；正文视口四周 2px 灰绿色内框，使用强调色与画布各 50% 混合。 |

**适用边界：**“不要双框”不等于移除所有键盘焦点。普通按钮仍需清楚的焦点提示。设置标签当前不使用外圈；Tab 导航时未选中标签的辨识度列入后续键盘复核，不把这一实现推广为隐藏焦点的原则。

## 4. 入口与工具分工

| 入口 | 负责什么 |
| --- | --- |
| 文件名旁的文档菜单 | 当前文档的历史版本／恢复入口 |
| 顶栏保存与导出 | 保存当前文档；导出 PDF 或带附件的文档 |
| 顶栏设置 | 外观与排版、保存与恢复；底部显示版本与构建标记 |
| 格式工具栏的“显示” | 文档属性、正文上方文件名、源码行号、编辑标记、标题多级编号 |
| 视图模式 | 编辑、阅读、源码 |
| 查找 | 当前文档内查找与替换 |
| 命令面板 | 按名称寻找功能，呈现已有快捷键 |
| 编辑工具栏 | 高频写作、插入与整理段落空行 |

“显示”是可连续切换多项的开关板。文档属性的显示开关只折叠或展开属性；有属性时不应删改 Markdown。阅读模式的工具栏保留“复制富文本”和“显示”。

命令入口使用“列表＋放大镜”线性图标，不显示“命令”二字，也不使用 macOS 专属的 ⌘ 作为功能图标。图标仍须有“命令面板”的可访问名称及悬停提示。

**图片、附件、提示块直接放在编辑工具栏。**不要用含义不清的“更多”收纳设置、文件和编辑操作。

### 命令面板

- 未搜索时按设置、文件、编辑、插入与格式、视图、恢复分组；搜索后显示匹配项。
- “设置”分组内直接写“外观与排版”“保存与恢复”；“显示选项”打开格式工具栏的显示控件。搜索“设置”仍能找到相关设置。
- 名称左对齐，快捷键右对齐；同一行只对应一个命令。
- “插入提示块”统一使用中文显示名，Callout 作为搜索别名。类型菜单使用中文名称和对应实心徽标，源码类型值保持不变。编辑区、阅读区、导出和菜单共用 Phosphor Fill SVG（MIT，许可证随资源保留）。图标 20px，与标题垂直居中；图样留白透出背景，不加额外圆圈，不使用 emoji。
- 提示块使用较重的语义图标，普通操作控件继续使用线性图标。按含义保留不同轮廓：信息 info、完成 check-circle、失败 x-circle、注意 warning、警告 warning-octagon、提示 lightbulb、笔记 note、摘要 text-align-left、待办 list-checks、问题 question、问题排查 bug、示例 flask、引用 quotes。色彩沿用提示块自身主题色。
- 命令搜索输入为专用规格：15px 字号、42px 高、9px 圆角。
- 无结果明确显示空状态；列表内部滚动，末项可通过鼠标和键盘到达。
- Tab 保持输入位置，方向键选命令，Enter 执行，Escape 关闭；中文组合输入期间不执行候选命令。

## 5. 设置与显示

设置保留两页，顺序为 **外观与排版 → 保存与恢复**。显示类开关位于格式工具栏的“显示”控件中。设置底部显示版本号和构建标记。

- 设置标签与内容之间保留一条中性细分隔线；内容使用整齐的行，不堆叠多层卡片和横线。
- 设置行的标签在左、控件在右。说明优先紧随对应标签，空间不足时同行内容自然换行。
- “仅影响显示，不修改原文”放在“显示”控件中“标题多级编号”右边。
- “¶ 段落结束　↵ 换行”放在“显示”控件中“编辑标记”右边；标签本身不再追加 ¶。
- 上述说明使用 12px 次级绿色文字。无需另设大段说明。
- 正文字号 14—24px，步进 1px；正文最大宽度 600—1100px，步进 20px。鼠标与方向键均可调整，数值右对齐。
- “历史版本与草稿保留时间”明确对象；期限下拉框窄一些，与标签页高亮宽度接近。下方“查看可恢复草稿”与其对齐。
- 设置始终位于查找等正文工具之上，不得出现看得见却点不到的标签。

## 6. 文件身份与文档属性

### L20 文件身份

macOS 窗口标题栏、工具栏文件名与页面文件名指向同一文件；文章 H1 属于正文，不替代文件名。

页面文件名前有轻量文件图标，下方使用与内容区同宽的细线。阅读模式的文件名不加正文标题折叠箭头。装饰不进入复制的原文或 Markdown。

双击 macOS 标题栏中央或页面文件名，在原地修改。Enter 提交，Escape 取消；离开输入位置取消并恢复正常显示。输入无大弹窗、无双框。保留目录与扩展名，拒绝覆盖同名文件，提交后同步各处名称。

### L21 文档属性

属性区使用轻底色和 8px 圆角，不用多层框线。底色为 `accent-soft` 35% 与 `canvas` 混合。

标题折叠箭头、字段类型图标、添加加号共用 28px 图标列；“文档属性”、字段名、“添加属性”的文字起点对齐。字段名为 12px 次级色／常规字重，值为正常主文字，避免靠粗框区分。

字段和值都可编辑。字段名拒绝空值和重复值；修改名称不应破坏值与注释。添加行分别提供“属性名”“属性值”。属性源码只显示对应 YAML；切换与删除分隔符不应卡死或吞入正文。

## 7. 保存、恢复与消息

### L30 提示寿命

| 类型 | 示例 | 寿命与操作 |
| --- | --- | --- |
| 成功／一般反馈 | 已重命名、已保存、已自动保存、无需整理 | 显示 4 秒后消失；新消息取消旧计时，旧计时不能清除新错误。 |
| 进行中 | 正在保存、等待自动保存 | 随任务结果更新；不能按固定时间伪装为成功。 |
| 待处理 | 选择保存位置、恢复后需要检查并保存 | 保留到相关条件解决。 |
| 错误 | 保存失败、文件被其他程序修改 | 可见且持续保留，说明下一步；不能因时间到而消失。 |
| 恢复入口 | 发现恢复记录 · 查看 | 可直接点击打开当前文档的历史版本与草稿；记录变化后刷新，无相关草稿时隐藏。 |

恢复入口独立于短暂成功消息；不要让用户读完提示后再到命令面板猜入口。当前实现中，恢复入口可见时，同区域的成功文字暂不显示，避免拥挤；错误仍需可见。

用户主动操作的成功／一般反馈通过独立的温和通知区域告知辅助技术。后台自动保存、自动保存开启和外部自动载入不重复播报；错误仍由可见错误区域通知。重复操作可再次通知，新状态取消尚未发出的旧通知。实际屏幕阅读器体验需单独验证。

### L31 恢复与删除

恢复面板先选记录、看预览，再恢复或作为新文档打开。原文件、当前编辑内容和恢复记录是不同对象，文案必须说明影响范围。

- 草稿动作名：**删除该草稿**；历史版本动作名：**删除该版本**。删除入口位于每条记录的文件名右侧，使用 16px 线性垃圾箱图标、28px 点击区域；常态弱化，悬停显示危险色，提供悬停提示和无障碍名称。窗口左下不再放独立删除按钮。点击后独立确认，不能直接删除。
- 点击后打开独立确认弹窗，显示文档名和“只删除选中的记录，无法撤销。原文件和其他记录不受影响。”
- 默认焦点在“取消”；Escape 取消。原面板暂不可操作，Tab 留在确认弹窗中。
- 不在同一按钮原地改字后接受第二次点击作为删除确认。
- 窗口底部只写“仅保存在本机，最多保留 20 个历史版本。”删除影响在确认弹窗说明，避免草稿与历史版本对象混用。
- 删除只针对被点击垃圾箱所属行的记录 ID，不以当前预览项代替；其他草稿、版本和原文件保留；记录已变化时拒绝删除旧目标。
- 成功后刷新列表、欢迎页入口及当前文档提示；失败显示原因，保留可重试和取消的路径。

删除真实记录的人工验收使用专用测试数据，不能拿用户文档的恢复记录做破坏性试验。

## 8. 快捷键、平台和输入

| 动作 | macOS | Windows |
| --- | --- | --- |
| 新建／打开／保存 | ⌘N / ⌘O / ⌘S | Ctrl+N / Ctrl+O / Ctrl+S |
| 导出 PDF | ⌘E | Ctrl+E |
| 循环视图：编辑 → 阅读 → 源码 | ⌘R | Ctrl+R |
| 命令面板／文内查找 | ⌘P / ⌘F | Ctrl+P / Ctrl+F |
| 设置 | ⌥⌘, | Ctrl+Alt+, |

显示与实际绑定都按系统选择；不能只换提示文字。macOS 的字母、数字、反斜杠、逗号及句号组合共用修饰键绘制与可访问名称。旧版 ⌘⇧E 导出绑定不再作为规范。平台转换仅用于界面快捷键，不能替换文档中的符号。

中文输入法没有候选窗口也可能影响快捷键处理；必须以实际输入状态验证。原生菜单、编辑区和属性输入中的同一快捷键应有一致结果，不触发第二个窗口或后台欢迎页。

## 9. 窗口、弹层与可达性

- Leaf 桌面配置的最小窗口为 900×480；至少对照常规窗口与最小窗口的明暗主题。浏览器测试可继续覆盖更窄的响应式布局，但不能称之为桌面最小窗口。
- 窄窗允许工具栏分行，不能把图片、附件、提示块等必要入口裁掉。
- 菜单在窗口边缘保留至少 8px，超高时内部滚动。上下文菜单不因正文滚动容器而不可达。
- 侧栏展开后正文重新排版，不覆盖正文；长文件名、省略路径可获取完整信息。
- 弹窗标题和动作可到达；大列表与预览内部滚动。嵌套确认只操作最上层，取消后返回触发位置。
- 保留控件名称、选中、展开与禁用语义。颜色之外还要有文字、勾选或形状提示。
- 页面缩放、长中文标签、键盘操作都应纳入复核；不要仅依据截图宣布交互通过。

## 10. 不再采用的做法

| 旧做法 | 当前规则 |
| --- | --- |
| “外观”里混放保存与恢复 | 统一“设置”，分两页；显示开关归工具栏 |
| “显示空行标记” | “显示编辑标记”，解释 ¶ 与 ↵ |
| 图片、附件、提示块藏入插入菜单 | 编辑工具栏常驻 |
| 用 ⌘ 代表命令面板 | 跨平台列表搜索图标 |
| 首项选中＋另一项悬停，同时亮两行 | 一个当前候选 |
| 输入框边线叠粗焦点外框 | 相应控件使用单层细边线 |
| 紫红阅读框／仅顶部细线 | 灰绿色四周内框＋模式控件状态 |
| 大弹窗重命名文件 | 文件名原地修改 |
| 提示用户去命令面板找恢复记录 | 提示本身可直接打开 |
| 成功提示常驻 | 4 秒消退 |
| 同一位置连点确认，整批清理 | 独立确认，只删除选中记录 |
