# AI 辅助编辑与 MCP 连接

通过 MCP 连接，让 AI 读取、修改和审阅 Leaf 中的文稿。这份说明帮助你完成连接，并在日常写作中使用 AI 辅助编辑。

Leaf 目前支持通过 MCP 连接 **ChatGPT、Claude（桌面版）和 WorkBuddy**，辅助编辑与审阅文稿。使用前需完成对应软件的 MCP 连接配置。

## 让 AI 帮你连接

**直接在你熟悉的 AI 软件中使用 Leaf。** 无需另行为 Leaf 配置模型 API，也不必使用 Codex、Claude Code 等编程工具。连接后，你可以沿用所选 AI 软件及其账号，在对话中提出修改要求。

MCP 是连接 Leaf 与 AI 软件的方式。你无需了解它的技术细节，也可以把这份说明交给 AI，请它协助完成设置：

> 我想把 Leaf 连接到我使用的 AI 软件。请根据这份说明，先确认我的操作系统和 AI 软件，再逐步指导我完成配置。需要登录、授权或填写密钥时，请告诉我在哪里操作。最后，请读取我在 Leaf 中打开的示例文稿，确认连接成功，暂时不要修改内容。

AI 可以提供操作指导；具备电脑操作能力的 AI 还可以协助完成部分设置。账号登录、授权和密钥输入由你在对应界面完成，不要把密钥发到对话中。

使用仍受所选 AI 软件的账号权限、订阅与用量限制。ChatGPT 的连接还需要一个隧道密钥，用来建立连接；它与为 Leaf 配置模型 API 是两回事。

## 选择连接方式

先打开 Leaf 桌面版，进入“设置 → AI 辅助编辑”，开启“启用 MCP 连接”，再选择要连接的 AI 软件。使用期间保持 Leaf 和需要处理的文稿打开。

| AI 软件 | 连接方式 |
| --- | --- |
| ChatGPT | 通过 OpenAI 隧道连接，需要准备隧道标识、连接程序和连接密钥。 |
| Claude Desktop | 从 Leaf 添加扩展，在 Claude 中确认安装。 |
| WorkBuddy | 从 Leaf 添加连接，再在 WorkBuddy 中启用。 |

只需完成你所使用的软件对应的步骤。不同客户端的配置分别保存，切换设置中的软件选项不会清除其他连接。

### ChatGPT

Leaf 使用 OpenAI 的安全隧道，让 ChatGPT 连接到电脑上正在运行的 Leaf。首次配置可以请 AI 对照 [OpenAI 隧道指南](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)协助完成。

1. **准备隧道。** 从 Leaf 设置中的链接打开 OpenAI 隧道设置，创建或选择一个 Leaf 专用隧道，将 Tunnel ID 填回 Leaf。确认该隧道关联了你要使用的 ChatGPT 工作区，并具备创建、使用隧道所需的权限。
2. **选择连接程序。** 按 Leaf 中的下载入口，下载适合系统与芯片的完整官方 `tunnel-client` 程序包并解压。在 Leaf 中选择解压后的程序；Windows 对应 `tunnel-client.exe`。请把整个解压文件夹放在准备长期保留的位置。
3. **填写连接密钥。** 将 Runtime API key 输入 Leaf 的连接密钥栏，保存配置。密钥用于隧道连接，请勿放入聊天、截图或问题反馈。保存后输入框会清空；以后修改配置时留空，可以保留已有密钥。
4. **在 ChatGPT 添加 Leaf。** 保持 Leaf 的 MCP 连接开启，待本地服务就绪后，在 ChatGPT 网页的插件页面添加自定义 MCP 服务器，连接方式选择 Tunnel，并选择同一个隧道，将 Authentication 设为 **No authentication**（仅适用于此处的 Tunnel 连接；组织与工作区访问权限仍然适用）。按页面提示完成创建和安装。具体入口见 [ChatGPT 自定义 MCP 连接说明](https://developers.openai.com/api/docs/guides/custom-mcp-server)。
5. **确认可以读取。** 在 ChatGPT 对话中通过 `@` 选择已安装的 Leaf 插件，请它读取一份已在 Leaf 中打开的示例文稿。

如果账号中没有对应入口，或列表中找不到隧道，先核对账号权限和工作区关联。界面与可用范围以 OpenAI 当前说明为准。

### Claude Desktop

1. 在 Leaf 中选择 Claude Desktop，点击“添加到 Claude”。
2. 在打开的 Claude 扩展安装界面中，确认安装 Leaf。
3. 保持 Leaf 打开并开启 MCP，在 Claude 对话中选择 Leaf，请它读取一份示例文稿。

正常安装流程无需手工修改配置文件，也无需另行安装 Node 或 Python。

### WorkBuddy

1. 在 Leaf 中选择 WorkBuddy，点击“添加到 WorkBuddy”，确认添加连接。
2. 在 WorkBuddy 的“专家·技能·连接器 → 连接器 → 自定义连接器”中启用 Leaf。如果连接未出现，重新启动 WorkBuddy 后查看。
3. 保持 Leaf 打开并开启 MCP，在 WorkBuddy 对话中直接提出读取示例文稿的要求，无需从“+”菜单选择 Leaf。

Leaf 会备份原有配置，并保留其他连接和设置。

### 怎样确认连接成功

在 Leaf 中新建一份只写有几句话的示例文稿，再向 AI 提出：

> 请通过 Leaf 连接读取我打开的示例文稿，并概括它的内容。不要修改。

AI 能通过连接读出当前文稿，才说明这一步已经完成。“配置已保存”或“本地服务已就绪”表示连接准备取得进展，还需要这次实际读取来确认。

## 开始写作与审阅

连接后，你可以通过 AI 阅读和梳理文稿、润色或修改正文、整理文档属性、编辑脚注与表格，也可以让它添加审阅批注，或根据已有批注修改文稿。直接在对话中说明需要完成的工作，以及是提出建议还是直接修改即可；同时打开多份文稿时，请写明文件名。修改结果会呈现在 Leaf 中，方便你对照检查和继续编辑。

### AI 可以访问哪些内容

开启 MCP 并启用对应客户端后，AI 可以访问 Leaf 中**当前打开的文稿，包括尚未保存的内容**。相关文本会发送到你使用的 AI 服务，请按文稿内容和自己的需要决定是否启用。

Leaf 的 MCP 连接不会让 AI 扫描文件夹、读取最近文件列表或自行打开电脑上的其他文件。关闭某份文稿后，该连接不能继续访问它；关闭 MCP 则停止全部连接访问，但不会撤回已经发送给 AI 服务的内容。

## 掌握修改过程

### 查看与结束编辑

AI 开始编辑后，Leaf 会显示编辑提示。此时该文稿暂时只读，你仍可浏览、滚动和查找，也可以继续编辑其他未被占用的文稿。同一份文稿一次只允许一个 AI 编辑任务。

需要中止时，点击提示条中的“结束编辑”。**结束编辑会保留已经完成的修改，并恢复手动编辑；它不会自动撤回修改。**

### 检查、撤销与保存

任务结束后，请在 Leaf 中检查修改结果。如果不满意，可以使用撤销，一次撤回该 AI 任务的修改；也可以重新提出更具体的要求。

“修改已应用”表示文稿内容已经更新，“已保存”才表示内容已写入文件。请留意保存状态；尚未选择保存位置的新文稿，仍需先保存为文件。自动保存与草稿恢复的区别，见[安装与使用说明](INSTALL.zh-CN.md#打开与保存文稿)。

### 在对话旁阅读文稿

支持实时阅读面板的 AI 软件，可以在对话旁显示 Leaf 文稿。你可以请 AI“打开这份文稿的实时阅读视图”，对照正文、属性、脚注和批注查看结果。

该视图用于阅读，手动编辑仍在 Leaf 中完成。能否显示面板取决于 AI 软件的支持情况；普通文件附件或静态预览不会随 Leaf 中的修改自动更新。

## 连接遇到问题

| 遇到的情况 | 可以先做什么 |
| --- | --- |
| AI 找不到文稿 | 确认 Leaf 正在运行、MCP 已开启、对应客户端已启用，且文稿已打开；再让 AI 重新读取当前文稿列表。 |
| 配置已保存，但 AI 仍无法读取 | 检查 AI 软件中是否已安装并启用 Leaf。使用 ChatGPT 时，还需核对是否选择同一个隧道，以及工作区关联和权限是否正确。 |
| AI 编辑中断或文稿暂时只读 | 查看 Leaf 提示，必要时点击“结束编辑”。检查已完成的修改，再让 AI 重新读取当前文稿并继续。 |
| 修改后没有保存成功 | 查看保存提示。新文稿先选择保存位置；遇到文件冲突时，保留当前内容，按提示处理或另存为。 |
| 更新后是否需要重新配置 | 在同一系统用户下，保留原安装位置、不卸载也不清空数据目录，正常覆盖安装会保留持久设置与应用数据。此说明不包含更换用户、迁移数据或移动隧道程序目录的情况。临时连接需要重新建立；外部 AI 软件（包括 ChatGPT）的 MCP 授权可能需要重新确认。 |

### 关闭或清除连接

暂时不需要 AI 辅助时，可以关闭“启用 MCP 连接”。已有连接配置会保留，正在进行的编辑任务会结束，已完成的修改也会保留。

如果不再使用某个客户端，可以在其设置中清除连接配置。清除前请确认选中的软件；其他客户端配置与文稿不会因此删除。AI 软件中的 Leaf 插件，以及 OpenAI 平台上的隧道和密钥，需要在对应软件或平台中另行管理。

仍无法解决时，欢迎通过 [GitHub Issues](https://github.com/CoozeeWang/leaf-markdown/issues) 反馈。请附上操作系统、Leaf 与 AI 软件版本、操作步骤和错误提示；截图中请移除文稿私人内容与密钥。
