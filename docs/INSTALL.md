# 安装与试用

Leaf 是本地 Markdown 编辑器，目前为 Beta。安装包与校验值来自 [GitHub Releases](https://github.com/CoozeeWang/leaf-markdown/releases)，不要从不明转载处安装。

## Windows x64

下载名称带 `windows-x64-setup.exe` 的文件，关闭已有 Leaf 后安装，再从桌面或开始菜单打开。可覆盖旧版，不需先卸载或清空设置。首次试用建议复制一份文档，检查编辑、保存、关闭重开后再处理原件。版本和构建号位于右上角齿轮设置面板底部。

Windows 安装包暂未做发行签名，浏览器或安全软件可能拦截下载。遇到拦截时保留原提示和包名，反馈给提供者核对来源与校验值；不要关闭防护或添加排除项。安全软件扫描结果与下载信誉是不同检查。

本轮安装版在 Windows 10 22H2、x64 上完成主要功能与修复验收；构建机检查不代表其他 Windows 版本/ARM 机器已经实测。应用使用 WebView2；首次安装若缺运行环境，安装器可能需要联网准备。

## macOS Apple Silicon

下载名称带 `macos-arm64.zip` 的文件，解压后将 Leaf.app 放到“应用程序”。更新时先正常退出旧 Leaf，再替换应用；不删除应用数据。当前附件仅适用于 M 系列 Mac，未提供 Intel 或通用包。

当前 Mac 包未做 Apple 发行签名/公证，其他电脑可能出现系统安全提示。保留提示并反馈给提供者核对，勿关闭系统保护。不要把本机运行成功当成另一台机器安装已通过。

## 已知边界

- 这一轮验收面向日常主要功能、文件保存恢复及本轮修复；完整屏幕朗读、对比度和全部语言/主题/缩放组合保留后续专项。
- 少数 PDF 标题元数据乱码仍在观察；正文、图片、代码及尾段需以实际导出成品为准。
- 本地附件只能在文档目录范围内解析，支持的外部链接为 HTTP、HTTPS、mailto；未支持的自定义协议不会自动打开。

试用反馈请附产品版本/构建号、Windows 或 Mac、复现步骤。截图与示例只用副本或合成文档，不提交私人资料。
