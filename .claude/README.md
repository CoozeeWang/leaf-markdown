# Project attribution settings

`settings.json` disables Claude Code's generated commit trailers, PR attribution and session links for this repository. It does not change permissions, hooks or safety settings. Follow the truthful contribution policy in [AGENTS.md](../AGENTS.md); retain legitimate contributor credit.

See the [Claude Code settings reference](https://code.claude.com/docs/en/settings-reference) and [project settings scope](https://code.claude.com/docs/en/settings).
